# meltonyan.dev

Portfolio for David Meltonyan. One HTML file, no build step.

- `index.html`: the whole site. Featured projects are written in the page; the "Everything on GitHub" grid loads live from the GitHub API.
- To feature or hide a repo in the live grid, edit `PIN` and `HIDE` near the bottom of `index.html`.
- To show a **Live demo** button on any repo, set its *Website* field on GitHub (repo page → ⚙ next to About).
- `resume.pdf`: replace with a file of the same name to update every resume link.
- `CNAME`: custom domain (meltonyan.dev). GitHub Pages serves the site from `main` / root.
