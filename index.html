Fraud Triage

Fraud models are easy to train and hard to act on. This system turns a LightGBM fraud probability into a decision (approve, send to an analyst, or block) by comparing expected dollar cost under a fixed daily review budget, then gives analysts a review app with the reasons behind each score.

  • Leak-free by test. Time-based splits only, and a test proves no feature can see the future.
  • Calibrated scores. Platt scaling on a held-out month so probability × amount means real dollars.
  • Runs on free hosting. Scoring is offline; the API serves precomputed results and a test checks it never imports the model.

Backend · LLM infrastructure

CostMelt

A drop-in HTTP proxy that sits between an app and LLM providers and cuts inference cost without client code changes: it classifies prompt complexity and routes to the cheapest capable model, serves semantically similar prompts from cache, compresses prompts, and micro-batches requests.

  • Routing engine with a complexity classifier across OpenAI, Anthropic, Groq and DeepSeek.
  • Semantic cache on pgvector embeddings with Redis TTL and LRU eviction.
  • Per-request cost attribution surfaced in a Next.js analytics dashboard.

A professional-research assistant that finds the right recruiter, hiring manager or founder from public sources, shows the evidence behind each data point, and drafts a context-aware introduction. Built to be explicitly not a scraper or spam tool.
